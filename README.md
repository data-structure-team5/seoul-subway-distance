# 서울 지하철 약속장소 추천 및 경로 안내 프로그램

> 이 문서는 프로젝트 개요, 빌드·실행 방법, 사용 데이터, 자료구조 활용과 핵심 로직을 소개합니다.
> 광운대학교 2026-2학기 「자료구조」 5조 팀 프로젝트입니다.

## 프로젝트 개요

여러 사람이 각자 다른 역에서 출발할 때, **가장 오래 걸리는 사람의 이동 시간이 가장 짧은 역**을 약속장소로 추천하고, 사람별 경로를 안내하는 C++ 콘솔 프로그램입니다.

1. 서울교통공사 역간거리·환승 데이터를 읽어, 역을 정점으로, 역 사이 이동·환승 시간을 간선으로 하는 **인접 리스트 그래프**를 만듭니다.
2. 사용자가 출발역을 입력하면, 출발역마다 **최소 힙 기반 다익스트라**를 실행해 모든 역까지의 최소 시간과 직전 정점(prev)을 구합니다.
3. 도착역을 정하지 않았다면 역마다 점수를 매겨 **병합 정렬**로 상위 5곳을 추천합니다.
4. 정한 도착역에서 prev를 거꾸로 따라간 경로를 **스택**으로 뒤집어, 출발역부터 소요시간·환승 횟수와 함께 출력합니다.

## 빌드 및 실행

C++17 컴파일러(g++ 등)가 필요합니다. 저장소 최상위 폴더에서 실행하세요. 프로그램이 `data/` 폴더를 상대 경로로 읽습니다.

```bash
g++ -std=c++17 -O2 -static src/*.cpp -o subway
```

```bash
./subway
```

- `-static`: Windows에서 Git Bash 등 다른 MinGW 환경의 `libstdc++-6.dll`이 먼저 잡히면, 실행 중 오류가 나거나 데이터 로드에 실패할 수 있습니다. `-static`으로 빌드하면 표준 라이브러리가 실행 파일에 포함되어 이 문제를 피할 수 있습니다.
- CSV 인코딩(CP949) 변환에 Windows API를 사용하므로, 현재는 Windows에서만 빌드됩니다.

## 사용 데이터

| 구분 | 파일 | 데이터명 | 용도 |
|---|---|---|---|
| 기본 | `data/station_distance.csv` | 서울교통공사_역간거리 및 소요시간 | 같은 호선 인접 역 사이의 이동 시간 |
| 추가 | `data/transfer.csv` | 서울교통공사_환승역거리 소요시간 정보 | 환승 시간을 경로 비용에 반영 |

- 두 파일 모두 **CP949 인코딩**이며, 프로그램이 읽을 때 UTF-8로 변환합니다.
- 범위는 **1~8호선**입니다. 환승 데이터 중 다른 노선(공항철도, 경의중앙선 등)으로의 환승은 제외합니다.
- 시간은 `"mm:ss"` 형식을 **초 단위 정수**로 바꿔 사용합니다. (예: `02:30` → 150)
- 역 이름은 앞뒤 공백을 제거하고, `총신대입구`는 `이수`로 통일합니다.
- 2호선·6호선(응암) 순환 구간과 지선 3곳(성수–용답, 신도림–도림천, 강동–둔촌동)은 별도로 연결합니다.
- 정점은 (역, 호선) 단위로 만들어 **277개**이고, 고유한 역 이름은 **240개**입니다.

## 자료구조 활용

| 자료구조 | 적용 대상 | 주요 연산 | 선택 이유 | 파일 |
|---|---|---|---|---|
| 그래프(인접 리스트) | 지하철 노선도 | 이웃 정점 순회 | 역마다 이웃이 2~4개뿐이라 인접 행렬보다 메모리·시간이 적게 듦 | `Graph` |
| 최소 힙 | 다익스트라 | 넣기, 최솟값 꺼내기 | 아직 확정 안 된 정점 중 가장 빠른 정점을 매번 빠르게 골라야 함 | `MinHeap`, `Dijkstra` |
| 이진 탐색 트리 | 역 이름 검색 | 삽입, 검색 | 역 이름 → 그 역의 모든 호선 정점을 빠르게 찾음 | `StationBST` |
| 스택 | 경로 출력 | push, pop | 도착역부터 거꾸로 구한 경로를 출발역부터 순서대로 출력 | `PathPrinter` |
| 큐(BFS) | 데이터 검사 | 넣기, 꺼내기 | 노선도가 끊긴 곳 없이 모두 이어져 있는지 확인 | `PathPrinter` |
| 병합 정렬 | 약속장소 순위 | 나누기, 합치기 | 점수가 같은 후보의 순서가 바뀌지 않는 안정 정렬 | `Meeting` |

## 핵심 로직: 공평한 약속장소 추천

1. 출발역 2곳 이상을 입력받고, BST에서 각 역의 모든 호선 정점을 찾습니다.
2. 사람마다 다익스트라를 한 번씩 실행해 `dist[p][v]`(p번 사람이 정점 v까지 가는 최소 시간)를 구합니다.
3. 역 이름별로 정점을 묶고, 사람마다 그 역의 정점 중 가장 빨리 도착하는 시간을 고릅니다.
4. 역마다 **가장 오래 걸리는 사람의 시간(max)**과 **모든 사람의 시간 합(sum)**을 계산합니다. 한 명이라도 갈 수 없는 역은 제외합니다.
5. max가 짧은 순으로, 같으면 sum이 짧은 순으로 병합 정렬해 상위 5곳을 보여 주고, 사용자가 하나를 고릅니다.
6. 사람마다 고른 역에서 prev를 거꾸로 따라가며 스택에 넣었다가 꺼내, 경로·소요시간·환승 횟수를 출력합니다.

### 복잡도

| 연산 | 자료구조 | 복잡도 |
|---|---|---|
| 최단 시간 계산 (다익스트라 1회) | 최소 힙 + 인접 리스트 | O((V + E) log V) |
| 약속장소 순위 정렬 | 병합 정렬 | O(V log V) |
| 역 이름 검색 | BST | 평균 O(log V) |
| 연결 검사 | 큐(BFS) | O(V + E) |

V는 정점 수(277), E는 간선 수입니다. 출발역이 k곳이면 다익스트라를 k번 실행하므로 전체는 O(k (V + E) log V)입니다.

## 프로젝트 구조

```
data/
  station_distance.csv   역간거리 및 소요시간
  transfer.csv           환승역 거리 및 소요시간
src/
  main.cpp               전체 흐름 (입력 → 계산 → 출력)
  Graph.h/.cpp           CSV 읽기, 인접 리스트 그래프
  MinHeap.h/.cpp         최소 힙
  Dijkstra.h/.cpp        다익스트라
  StationBST.h/.cpp      역 이름 이진 탐색 트리
  PathPrinter.h/.cpp     경로 출력(스택), 연결 검사(BFS)
  Meeting.h/.cpp         약속장소 순위(병합 정렬)
```
